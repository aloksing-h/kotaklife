Authoring Flow

  1. Insert the Plans Explorer block
  2. Write the title + description in the RTE - "Find a plan that fits you / Explore across protection, savings, health, and retirement"
  3. Add Tab Item children - one for each category (write tab label in RTE)
  4. Inside each tab, add Plan Card items
  5. In each plan card: select the image, then write badge + name + description + link in the text RTE
  6. Add a Button below the block - "Browse All Plans", primary type

CTA cards can't use the cards block because they need Swiper.js integration. Single RTE is fine here since carousel cards are simpler visually. Image, badge, headline, description, and link all go in the RTE.

Authoring Flow

  1. Insert the CTA Carousel block
  2. Write the headline + description in the RTE - "Get ₹2 Crore cover for ₹80/day / Description text here"
  3. Set the Button Link - link to premium calculator
  4. Add CTA Card items - write badge + offer + description + image + link all in the RTE

Swiper.js Note

Swiper.js Integration:
  • The carousel functionality is delegated to Swiper.js - no custom carousel code needed
  • The block JS wraps authored cards in Swiper structure and initializes the library
  • Config: fraction pagination ("01/02/03"), autoplay (4s delay), creative slide effect
  • Mobile shows 1 card at a time, desktop shows partial next card for depth effect

Block 3: Company Stats

ID: company-stats

What it does: A grid with an MD quote card on the left and key statistics cards on the right. Each stat has a value, label, and illustration image.

MD Quote eliminated. The first stat-card is the quote card — block JS detects it by position and applies the quote layout (left column with photo + quote styling). Use "Quote + Stats" style for the full layout, "Stats Only" for a 3-card grid without the quote.

Authoring Flow

  1. Insert the Company Stats block
  2. Select "Quote + Stats" style from the dropdown
  3. Add Stat Card children:
  4. 1st card (quote): write quote + attribution + photo in the RTE
  5. 2nd-4th cards (stats): write value + label + illustration image in the RTE

Authoring Notes

  • The first child is always the quote card - block JS applies quote styling to it
  • Use the quote RTE to write: <blockquote>quote text</blockquote> + <cite>attribution</cite> + <img src="photo">
  • Stat cards: write <h2>38 million</h2> + <p>Lives covered nationwide</p> + <img src="icon">
  • Animated counter triggers when stats scroll into view (JS parses the <h2> text for the number)
  • On desktop: quote left column, stats grid right column. On mobile: everything stacks.

Post-Creation Steps

  1. Run npm run build:json to regenerate aggregated component definition/model/filter files.
  2. Run npm run lint to validate JSON models and code style.
  3. Start dev server with npx -y @adobe/aem-cli up --no-open to test blocks locally.
  4. Create test content in drafts/ folder with --html-folder drafts flag.
  5. For CTA Carousel: verify Swiper.js library loads correctly and carousel renders with pagination.
