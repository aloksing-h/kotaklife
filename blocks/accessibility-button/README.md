# Accessibility Button

A fixed accessibility control matching the Kotak Life desktop and mobile Figma design.

## Authoring

- Add an accessibility icon image.
- Add alternative text for the icon and control.
- Choose left or right viewport positioning.
- Provide the accessible button label.

The control opens an accessibility panel with contrast, larger text, link underline, reduced motion, and reset options. Double-clicking or double-tapping the control switches its side.
